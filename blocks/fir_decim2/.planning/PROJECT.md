# fir_decim2 — 25-tap symmetric decimate-by-2 polyphase FIR

## What This Is
A streaming low-pass FIR that halves the sample rate, written in SystemVerilog for AMD RFSoC (UltraScale+). Spec: `../SPEC.md`.

## Core Value
Coefficient symmetry is turned into hardware savings: 25 taps -> 13 multipliers via DSP48E2 pre-adders, at full input throughput.

## Requirements (validated)
- Bit-exact against a scipy `lfilter(h,1,x)[::2]` golden model, on Icarus and Verilator (cocotb).
- 13 or fewer multipliers; polyphase so every multiplier runs at the output rate.
- Sample-driven (in_valid gaps do not change results), constant documented latency.
- Full-precision 39-bit output, no internal overflow at full scale.

## Context
- Coefficients: `scipy.signal.firwin(25, 0.4, 'hamming')` Q1.17 (generated by `tools/gen_fir_coefs.py`). Cutoff 0.4 not 0.5: a half-band filter would zero every even tap and hide the symmetry story.
- Yosys `synth_xilinx -family xcup` is the on-machine estimate; the Vivado tcl in `synth/` is the RFSoC sign-off.

## Constraints
- Open-source tools only on the demo machine; no Vivado run here.
- Target clock 300 MHz (assumed RFSoC fabric target; not timed here).

## Key Decisions
| Decision | Rationale | Outcome |
|---|---|---|
| Polyphase (even/odd branches) rather than full-rate FIR + decimate | each multiplier does one product per output sample, half the DSP cycles | ✓ Good |
| Pre-add pairs coded as (a+d)*b with registered a/d, pre-add, product | the pattern Vivado infers DSP48E2 pre-adder (A+D)*B from | ✓ Good (Yosys maps 11 DSP48E2; see metrics) |
| Pipelined fabric adder tree instead of DSP post-adder cascade | 7-cycle latency instead of ~13 output periods; cascade is a v2 option | ✓ Good |
| h[2] and h[7] quantize to exactly 0 | their products are constant 0 and synthesis removes them: 11 real multipliers | ✓ noted in metrics |
